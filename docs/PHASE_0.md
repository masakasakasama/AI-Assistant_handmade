## Phase 0合格条件

文字分類だけで合格しない。日英独で会話の満足度と重要パラメータ精度を満たし、
STT→LLM→TTSと物理操作の応答目標を測定し、誤操作・重複・復旧に未解決の重大問題がないこと。
目標と測定点は[PERFORMANCE](PERFORMANCE.md)。固定テストで誤操作ゼロでも一般保証ではない。
