# 音声認識の測定（v0.4.25 → v0.4.26）

2026年10月1–2日（UTC）に公開バックエンド `/api/transcribe` を測定しました。ドイツ語の文字起こしが合っていても、音声モデルが言語を日本語と返す不整合を発見し、v0.4.26で文字起こしに対する言語チェックを追加しました。

|---|---:|---:|---:|---:|---:|
| 人のドイツ語 | 42 | 31/42（73.81%） | 42/42（100%） | +26.19ポイント | 14.02% → 14.02% |
| 上記の一部＋10 dBの雑音 | 14 | 8/14（57.14%） | 14/14（100%） | +42.86ポイント | 8.91% → 8.91% |
| 人の英語 | 14 | 14/14（100%） | 14/14（100%） | 0ポイント | 10.50% → 10.50% |
| 合成ドイツ語 | 7 | 7/7（100%） | 7/7（100%） | 0ポイント | 1.72% → 1.72% |
| 合成日本語 | 7 | 7/7（100%） | 7/7（100%） | 0ポイント | CER 0% → 0% |

84件すべて、ケースIDと送信WAVのSHA256が前後で一致しています。HTTP成功は前後とも84/84件。文字起こしは82/84件で文字列まで一致し、残り2件も正規化後の誤り数は同じでした。今回改善したのは言語ラベルです。文字起こし自体の改善率は示していません。

修正後のドイツ語42/42件のWilson 95%区間は91.62–100%、雑音14/14件は78.47–100%です。この標本での100%を、あらゆる発話での100%として扱うことはできません。雑音ケースは元の42件の一部なので、独立した56話者の結果ではありません。

修正後のAPI往復時間の中央値は、ドイツ語988 ms、雑音939 ms、英語792 ms、合成ドイツ語618 ms、合成日本語701 msでした。録音時間、ウェイクワード、無音待ち、回答生成、読み上げ時間は含みません。4並列で測定した値です。

## 測定方法と限界

- 人の音声は [PolyAI MINDS-14](https://huggingface.co/datasets/PolyAI/minds14)（CC BY 4.0）のde-DE/en-US、revision `40ce77cb32a384e4d50a568e1ec39ac804019d33`。データと参照文の著作者・公開元はPolyAIです。銀行関連の14意図からドイツ語各3件、英語各1件を抽出しました。家庭用コマンド全般を代表する標本ではありません。
- 元の電話音声は8 kHz。16 kHz・mono・PCM16 WAVに変換しましたが、失われた高域は復元されません。元からある録音雑音も残っています。
- 最初のseedは20261001、追加標本は20261002。30秒超・0.25秒未満・空の参照文を除外し、その記録もJSONに残しています。最初に1件、追加で0件が除外されました。
- 雑音は各意図の最初のドイツ語標本14件に、sourceIdから定めたseedで白色雑音を追加。10 dB SNRは無音区間を含む音声全体に対する値です。雑踏・テレビ・残響の再現ではありません。
- 合成音声はEdge TTSのKatja/Conrad（ドイツ語）とNanami/Keita（日本語）を交互に使用。参照文・声名・音声ハッシュをJSONに記録しています。人の日本語は今回測っていません。
- 言語判定の正解は返却 `languages` が期待する1言語だけであること。混在ラベル・失敗も不正解に数えます。v0.4.26は `audioLanguages` と `languageSource` も記録し、音声だけの判定と文字起こしによる補正を区別します。
- WERは単語の挿入・削除・置換数÷参照語数、CERは同様の文字単位です。NFKC・小文字化・句読点除去を行い、数字と綴りは統一しません。失敗は空文字として数え、再試行はしていません。
- 公開参照文にも明らかな誤記があります。例：de-DE row 453の参照文は `Kater ein Kondom`、認識文は `Karte, ein Konto`。参照文を聞き直して手作業で修正した評価ではないため、WERは公開参照文との差であり、真の音響認識誤り率と断定できません。雑音ケースのWERが低いのも標本が異なるためで、雑音が精度を上げた証拠ではありません。
- Galaxyのマイク、Android録音・VAD、実際の発音、TTS、家庭機器実行は測っていません。旧Android SpeechRecognizer（v0.4.24）の測定結果もないため、その版からの改善率は計算できません。

## 生データと再実行

- [v0.4.25 全84件](stt-accuracy/v0.4.25.json)
- [v0.4.26 同じ84件](stt-accuracy/v0.4.26.json)
- [v0.4.26 未使用56件](stt-accuracy/v0.4.26-holdout.json)
- [測定スクリプト](../ai-backend/scripts/benchmark-stt.py)

JSONには各ケースの参照文・認識文・判定・時間・音声SHA256・データセット行/パスを収録しています。期限付き音声URL、認証情報、音声ファイルは収録していません。音声はローカルキャッシュに保存します。Python 3、numpy、ffmpegが必要です。

```sh
python ai-backend/scripts/benchmark-stt.py --cache /tmp/tatsu-stt --output /tmp/tatsu-stt/first.json
python ai-backend/scripts/benchmark-stt.py --cache /tmp/tatsu-stt --cases-manifest /tmp/tatsu-stt/first.manifest.json --output /tmp/tatsu-stt/repeat.json
python ai-backend/scripts/benchmark-stt.py --cache /tmp/tatsu-stt --exclude-manifest /tmp/tatsu-stt/first.manifest.json --seed 20261002 --no-noise --output /tmp/tatsu-stt/holdout.json
```

上記は人の音声70件と追加56件を再抽出するコマンドです。合成14件は `--fixtures` で別途渡します。完全な過去の84件の再送には記録したSHA256と一致する合成音声を含むキャッシュが必要です。API呼び出しには料金が発生します。データセットrevisionが変更されていた場合はスクリプトが停止します。
