# Tatsu Home UI設計

## 方向性

日常の道具として静かで上質に。Apple Homeの操作優先・大きいタップ領域を参考にするが、画面を模写しない。
チャコールとセージの背景、暖色のアクセント、揃った線画アイコンを使用。
明色はアイボリー、白いサーフェス、濃い文字。暗色でもアクセント上の文字コントラストを確保。

## 階層

1. TATSU HOMEと短い挨拶。同期・設定はアイコンボタン。
2. 日時と天気を一つの広いカードへ集約。天気を下に重複表示しない。
3. 次のアラームと家電、等幅の2列カード。内容量によって幅が変わらない。
4. AIへの入口。音声未実装の段階で「常時待受中」や偽のマイク操作を表示しない。
5. ホーム／家電／アラーム／AIの下部ナビゲーション。

ホームにはLuna、Sol、Wake、STT、Room、Exact Alarmなどの開発用語を表示しない。
AIラボは明示的に検証画面とし、提案表示のみで物理操作しないことを説明する。
サーバー時間と端末往復時間を区別し、分類時間と回答時間も表示。

## レイアウト

外側余白16dp（大型画面28dp）、カード間12〜18dp、角丸24〜28dp。
カードのSurface自体にfillMaxWidthを付ける。親のweightだけでは中身が列幅へ広がらない。
最小タップ領域48dp。文字拡大で重要操作が消えないか、長い家電名と空状態で確認。
次のアラームは時分順でなく実際の次回発火順。現在状態と送信した設定を混同しない。

大型画面の専用マスター／詳細UIは未実装。現段階は同じコードで幅に適応する基本レイアウト。
スマホとタブレット、暗色と明色を実際のAndroid画面で確認する。
